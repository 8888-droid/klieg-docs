---
title: "Glossary"
description: "Key terms used in Klieg Wire."
---

| Term | Meaning |
| --- | --- |
| Caller | A person or source account publishing token-related ideas |
| Platform account | A profile on a particular platform |
| Caller identity | A reviewed and approved grouping of one caller's accounts |
| Cohort | A user's chosen circle of callers |
| Global | Available activity without restriction to your cohort |
| Call | A caller's token-related post |
| Thesis | The content of a caller's idea about a particular token |
| Buy | A purchase confirmed by independent onchain data |
| Sell | A sale confirmed by independent onchain data |
| Call+buy | A matched post and confirmed purchase |
| Signal | A thesis with an assessment, context, and available evidence |
| Signal Dossier | A chronological account of a signal's evidence and events |
| Observed | An observation that does not yet imply final confirmation |
| Onchain | Information about blockchain state or events |
| Evidence | The basis of a specific claim, with its source and time |
| Attribution | An evidenced or explicitly qualified link between an event and a caller or wallet |
| Outcome | A post-call measurement at a specified horizon |
| Drawdown | A decline in measured value relative to a chosen reference point |
| Watchlist | Specific signals a user has saved |
| Pass | A Demo, Standard, or Gold contract-based access entitlement |
| SBT / soulbound | A non-transferable token bound to a wallet |
| Mint | Creation of an NFT upon a successful purchase |
| Allowance | The maximum token amount a particular contract is authorized to spend |
| SIWE | Sign-In with Ethereum: authentication using a signed message |
| USDC | The payment token; Klieg access uses its Base address |
| Gas | A network transaction fee; paid in ETH on Base |
| Chain ID | A numeric network identifier; Base Mainnet uses 8453 |

This glossary explains terminology. See [pricing](/en/access/pricing) for pass rules and the [evidence model](/en/concepts/evidence) for confirmation limits.
