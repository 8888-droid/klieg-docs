---
title: "Словарь"
description: "Основные термины Klieg Wire и английские подписи в интерфейсе."
---

| Термин | Значение |
| --- | --- |
| Caller / автор | Человек или исходный аккаунт, публикующий идеи о токенах |
| Platform account | Профиль на конкретной площадке |
| Caller identity | Рассмотренное и подтверждённое объединение аккаунтов одного автора |
| Cohort / группа | Выбранный пользователем круг авторов |
| Global | Обзор доступной активности без ограничения вашей группой |
| Call / публикация | Сообщение автора о токене |
| Thesis / тезис | Содержание идеи автора о конкретном токене |
| Buy / покупка | Покупка, подтверждённая независимыми ончейн-данными |
| Sell / продажа | Продажа, подтверждённая независимыми ончейн-данными |
| Call+buy | Сопоставленные публикация и подтверждённая покупка |
| Signal / сигнал | Тезис с оценкой, контекстом и доступными доказательствами |
| Signal Dossier | Последовательная история доказательств и событий сигнала |
| Observed | Наблюдение, которое ещё не означает окончательное подтверждение |
| Onchain | Сведения, относящиеся к состоянию или событиям блокчейна |
| Evidence / доказательство | Основание конкретного утверждения с источником и временем |
| Attribution / атрибуция | Доказанная или явно обозначенная связь события с автором или кошельком |
| Outcome / результат | Измерение после публикации на указанном временном горизонте |
| Drawdown / просадка | Снижение измеряемой стоимости относительно выбранной точки отсчёта |
| Watchlist | Сохранённые пользователем конкретные сигналы |
| Pass / пропуск | Контрактное право доступа Demo, Standard или Gold |
| SBT / soulbound | Непередаваемый токен, связанный с кошельком |
| Mint / выпуск | Создание NFT при успешной покупке |
| Allowance / разрешение | Максимальная сумма токена, которую разрешено расходовать определённому контракту |
| SIWE | Sign-In with Ethereum: подтверждение входа подписанным сообщением |
| USDC | Платёжный токен; для доступа Klieg используется его адрес в Base |
| Gas | Комиссия сети за транзакцию; в Base оплачивается ETH |
| Chain ID | Числовой идентификатор сети; у Base Mainnet это 8453 |

Словарь объясняет термины. Конкретные правила пропусков находятся в [тарифах](/ru/access/pricing), границы подтверждений — в [модели доказательств](/ru/concepts/evidence).
